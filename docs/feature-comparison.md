# 픽셀 RF feature 비교 — 2026-09-14

과거 선정: **hybrid-64**, CPDINO ViT-L 인코더 PCA 64차원 + 영상 특징 16채널.

현재 앱은 ViT-B로 전환했습니다. 아래 수치는 ViT-L 실험 기록이며 새 모델의 정확도를 나타내지 않습니다.

## 조건

- sample3 750×748. clean-train의 라벨 9,026픽셀로 학습.
- clean-dev 6,991픽셀로 선택. 배경 35, 대립 6,891, 소립 65픽셀로 불균형이 큼.
- 기존 holdout 417픽셀은 이미 사용된 자료이므로 참고 평가로만 보고.
- PCA는 같은 이미지 전체에서 균등 추출한 비라벨 토큰 최대 50,000개를 사용. 평가 위치의 영상 정보가 포함되는 같은 이미지 내 실험이며, 독립 이미지 평가가 아님.
- 모든 후보에서 같은 학습 좌표와 RF 설정 사용: 200 trees, depth 10, leaf 2, sqrt, balanced, seed 0.
- 후보 선택: 개발 라벨 대립·소립 F1 평균 우선. 영상 특징 대비 배경 F1 2%p 초과 하락 제외. 최고 점수와 1%p 이내면 피드백 시간 우선.

## 결과

| 후보 | 개발 대립·소립 평균 F1 | 개발 배경 F1 | 참고 대립·소립 평균 F1 | 캐시 사용 학습+예측 |
|---|---:|---:|---:|---:|
| 영상 16채널 | 60.03% | 30.40% | 58.46% | 2.26초 |
| 인코더 PCA 32 | 72.16% | 24.53% | 72.65% | 4.72초 |
| 인코더 PCA 64 | 63.99% | 52.63% | 55.60% | 6.90초 |
| 혼합 PCA 32 | 66.46% | 37.50% | 64.80% | 5.10초 |
| **혼합 PCA 64** | **71.86%** | **56.47%** | **56.46%** | **7.12초** |

인코더 PCA 32는 주 지표가 가장 높지만 개발 배경 F1이 기준보다 5.87%p 하락하여 제외했다.
나머지 후보 중 혼합 PCA 64가 최고였고, 다른 허용 후보와의 차이가 1%p 이상이라 속도 동률 규칙은 적용되지 않았다.
기존 참고 영역에서는 영상 특징보다 악화됐다. 경계 품질·소립 전반의 정확도 개선이나 다른 이미지의 일반화를 주장하지 않는다.

## 비용과 검증

RTX 2060 6GB, Python 3.13. 모델 로딩 제외 인코더+마스크 추론 8.82초, 영상 특징 0.49초.
PCA 학습 32차원 0.47초 / 64차원 0.66초, 토큰 투영 0.07 / 0.08초.
선택 구성의 학습 표본 준비 0.06초, RF 학습 0.72초, 전체 예측 6.34초.
캐시 크기: 영상 특징 34.24MiB, 압축 토큰 64차원 5.06MiB, 합계 39.30MiB.
특징 수집을 켠 추론과 끈 추론의 Cellpose 마스크 및 전경 logit이 byte 단위로 일치했다.

비교 프로세스 전체의 최대 RSS 약 2,146MiB, GPU peak allocated 약 2,191MiB, reserved 약 3,242MiB.
이 메모리 수치는 모델·비교 후보·임시 PCA 배열이 함께 존재하는 프로세스의 누적 최고치이며 후보별 독립 메모리 측정이 아니다.
`comparison.json`에는 후보별 시점 RSS와 누적 최고치, 클래스별 confusion/recall/F1, 단계별 시간이 있다.

실제 앱 API: 최초 Cellpose 제안(모델 로딩 포함) 19.56초, 제안 캐시 후 첫 학습 8.15초, 이후 라벨 교환/복원 6.84/6.93초.
라벨 교환으로 미라벨 픽셀 458,882개의 예측이 바뀌었고 원래 라벨을 복원하면 동일한 결과를 얻었다.
원본과 501×500 작업 해상도에서 단일 PNG와 ZIP의 최종 원본 크기 픽셀이 일치했다. 라벨 전체 삭제도 확인했다.
이 테스트는 학습 반영과 저장 일관성을 검증하며 정확도 평가가 아니다.
