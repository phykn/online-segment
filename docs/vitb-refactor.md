# ViT-B 전환과 폴더별 리팩토링

2026-09-14. 최종 분할은 픽셀 RF가 수행하며 CPDINO는 영역 선택과 특징 추출을 보조한다. 기본 가중치를 `weights/cpdino-vitb.pth`로 바꿨다.

## 변경 범위

| 폴더 | 점검 및 정리 |
|---|---|
| `backend/src/segment` | `encoder.py`가 정규화된 공간 토큰 수집·좌표 복원·PCA 투영을 담당한다. `feature.py`는 영상 특징과 RF 입력 조합, `cache.py`는 용량 제한 LRU를 담당한다. 런타임의 ViT-L 1024차원 고정을 제거하고 ViT-B 768차원을 지원한다. 체크포인트 변경 시 이전 모델 인스턴스를 재사용하지 않는다. |
| `backend/src/api`, `data`, `export` | 기존 API·클래스/인스턴스 RLE·원본 좌표·PNG 팔레트·ZIP 작업 수명은 유지했다. 모델 변경 후에도 동일 RF 결과를 저장하는지 검증했다. |
| `weights` | CPDINO ViT-B 가중치만 유지하고 Git LFS로 관리한다. 오래된 앱 외부 2×2 타일 실험과 일회성 검증 스크립트는 정리했다. |
| `frontend/src/model`, `editor` | 인스턴스 RLE·좌표 변환을 `instances.js`로 분리했다. 사용하지 않는 페인팅 제한 모듈과 화면까지 전달되던 미사용 summary/uncertainty 데이터를 제거했다. 예측·학습 요청과 브러시 동작은 유지했다. |
| `frontend/src/api`, `images`, `output`, `sidebar` | 세션, 이미지 전환, 저장, 버튼 배치를 점검했다. 현재 UI 동작과 영어 표기를 유지했다. |

RF 입력은 PCA 64 + 영상 16 + 영역 통계 14 = 94채널로 유지한다. 클래스 의미를 고정하지 않고, 사용자 라벨은 학습 예시로만 사용한다. 예측을 라벨에 편입하거나 라벨로 결과를 강제 덮어쓰지 않는다. 윤곽은 항상 표시하고 Prediction/Unclear/Edits는 독립적으로 동작한다.

## 가중치

[공식 CPDINO ViT-B](https://huggingface.co/mouseland/cellpose-sam/blob/main/cpdino-vitb)와 로컬 파일의 SHA-256이 일치한다.

`3ed4c06a3963ab13ff377d4e2957174aaaf637434eb031ae9931fcbfaf9a217f`

남은 파일은 343,599,997바이트다. 작업 시작 시 있던 ViT-L, SAM ViT-B, ScribblePrompt SAM/UNet 4개는 현재 폴더에 없으며, 총 1,980,068,783바이트가 정리된 상태다.

## 검증

- 백엔드: 66개 테스트와 21개 subtest 통과. ViT-B/ViT-L 토큰 수집, 오류 시 hook 해제, 모델 교체 시 재로딩 포함.
- 프런트엔드: 72개 테스트 및 production build 통과. 미사용 페인팅 제한 모듈 제거에 따라 해당 테스트 2개도 제거했다.
- `pip check`: 의존성 충돌 없음.
- 실제 GPU: RTX 2060 6GB, sample3 원본 750×748, ViT-B, 현재 94채널 RF.

| 단계 | 시간 |
|---|---:|
| 모델 로딩 | 4.488초 |
| 영역 찾기 + 토큰 수집 | 4.218초 |
| 토큰 수집 없는 기본 분할 | 2.978초 |
| PCA 학습 | 0.586초 |
| RF 특징 구성 | 0.534초 |
| 표본 추출 + RF 학습 | 0.859초 |
| 전체 픽셀 예측 | 6.682초 |
| 캐시 사용 라벨 수정·재학습·예측 | 7.285초 |

원시 토큰은 60.75MiB, 테스트 프로세스의 PyTorch 최대 GPU 할당량은 1,381.51MiB였다. 전체 시스템 VRAM 사용량과는 다르며 시간은 단일 실행 측정값이다.

토큰 수집 유무에 따라 분할 결과가 같았다. 홀수 크기 183×181, diameter 15/60에서도 분할 결과가 같았다. 기존 좌표 테스트는 내부 타일 겹침·패딩 제거·최종 보간 일치를 확인한다. 캐시가 있는 수정 단계에서는 모델 실행과 PCA 생성을 금지한 상태로 통과했고, 특징 캐시를 비워 재구성해도 예측이 같았다. 라벨 교환 후 미라벨 픽셀 554,442개가 바뀌었고 원래 라벨 복원 시 최초 예측으로 돌아왔다. 전체 라벨 삭제 시 미라벨 결과를 반환했다. 단일 PNG와 ZIP 내부 PNG는 바이트 단위로 같았다.

검증 결과와 측정값은 이 문서에 요약해 보존한다. 생성된 원시 파일과 일회성 검증 스크립트는 저장소에 포함하지 않는다.

기존 `sample3-feature-trial` 정답 파일은 현재 작업 폴더에 없어 이번에는 합성 희소 라벨로 동작만 검증했다. 과거 ViT-L F1 수치를 ViT-B 정확도로 해석하지 않는다. 이 결과로 두 모델의 정확도 동등성이나 일반화 성능을 주장하지 않는다.
