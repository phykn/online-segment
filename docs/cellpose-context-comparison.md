# Cellpose 통계 특징 추가 비교 — 2026-09-14

후속 변경: 사용자가 통계 입력을 사용하기로 결정하여 앱 기본값을 `statistics`로 변경했다. 면적을 별도 채널로 추가해 현재 통계는 14채널, 전체 입력은 94채널이다. 아래 수치와 당시 선택 결과는 변경 전 13채널 비교 기록으로 보존하며 현재 구성의 성능 측정으로 해석하지 않는다.

크기·형태 특징을 픽셀 RF에 추가하는 경로를 구현했다. 이번 고정 라벨 비교에서는 소립 재현율은 증가했지만 개발 배경 F1과 대립·소립 평균 F1은 하락했다. 기본 `feature.cellpose: none`을 유지하며 `foreground`와 `statistics`를 선택 가능한 설정으로 제공한다. 성능 문제가 해결됐다는 결론은 내리지 않는다.

## 구현과 조건

- 공통 입력: 기존 선정 구성인 영상 16채널 + CPDINO 인코더 PCA 64차원.
- `foreground`: sigmoid(Cellpose 전경 logit) 1채널 추가. 보정된 전경 확률이라는 의미는 아니다.
- `statistics`: 위 점수, 인스턴스 유무, 부호 있는 경계 거리, 등가 원 지름, 단축·장축, 축비, bounding box 채움 비율, 경계 픽셀 수/√면적, 입자 평균 전경 점수, 이미지 가장자리 접촉 여부, 입자 평균 밝기·밝기 표준편차. 총 13채널 추가.
- 경계 거리는 입자 내부 양수, 외부 음수이며 인접한 서로 다른 입자 사이도 경계로 취급한다. 검출 입자가 전혀 없으면 0이다. 배경 위치의 입자 통계는 0이지만 영상·인코더·전경 점수는 남는다.
- 지름·축 길이·거리는 원본 너비/작업 너비를 곱해 원본 픽셀 단위로 환산한다. 실제 μm 단위 보정이나 다른 촬영 배율의 동일 크기를 보장하지 않는다.
- 사용자 라벨·RF 예측으로 통계를 계산하지 않는다. Cellpose 마스크로 최종 RF를 자르거나 입자별 다수결을 적용하지 않는다.
- 동일 forward에서 공간 토큰·분할 출력을 얻는다. 통계는 낮은 차원의 맵과 인스턴스 lookup table로 보관하며 필요한 픽셀만 RF에 전달한다.

sample3 750×748의 기존 clean-train 9,026픽셀로 학습한다. clean-dev는 배경 35, 대립 6,891, 소립 65픽셀이다. 기존 holdout 417픽셀은 참고용이다. 학습/평가 라벨의 중첩은 없다. 모든 구성에 동일한 표본 좌표·PCA·RF 설정(200 trees, depth 10, leaf 2, sqrt, balanced, seed 0)을 적용했다.

PCA는 평가 위치까지 포함한 같은 이미지의 비라벨 토큰으로 학습했다. 여러 번 사용한 희소 내부 라벨 실험이며 새 전문가 정답이나 독립 이미지 평가가 아니다. 라벨을 추가·수정하지 않았다.

이번 배경 개선 요청에 맞춰 실행 전 선택 조건을 정했다: 기존 구성보다 배경 F1이 낮아지지 않고 대립·소립 평균 F1 하락이 1%p 이내인 후보 중 배경·대립·소립 macro F1이 가장 높은 후보를 선택한다. 1%p 이내 차이는 피드백 속도로 선택한다. 두 추가 후보 모두 이 조건을 통과하지 못했다.

## 결과

| 구성 | 개발 배경 F1 | 개발 대립 F1 | 개발 소립 F1 | 개발 소립 재현율 | 개발 대립·소립 평균 F1 | 참고 대립·소립 평균 F1 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 80채널 | 56.47% | 99.04% | 44.68% | 64.62% | 71.86% | 56.46% |
| + 전경 점수, 81채널 | 51.11% | 98.80% | 35.51% | 58.46% | 67.16% | 57.75% |
| + 통계, 93채널 | 42.20% | 98.14% | 35.61% | 92.31% | 66.87% | 85.98% |

통계 추가로 개발 소립 65픽셀 중 맞힌 수는 42→60으로 증가했다. 동시에 개발 대립을 소립으로 잘못 예측한 수는 80→202, 대립을 배경으로 예측한 수는 22→47로 증가했다. 크기 특징은 소립을 찾는 데 도움이 되었으나 이번 라벨에서는 다른 클래스의 오분류도 늘렸다. 참고 영역의 큰 개선만으로 기본값을 선택하지 않았다.

혼동행렬은 행=정답, 열=예측, 배경/대립/소립 순서이다. 상세 클래스별 재현율과 참고 혼동행렬은 JSON에 있다.

```text
기존:        전경 점수:    통계:
24 10  1     23  8   4     23  2  10
22 6789 80   27 6757 107   47 6642 202
 4 19 42      5 22  38      4  1  60
```

개발 배경 표본이 35픽셀뿐이고 대립이 대부분인 자료이므로 픽셀별 경계 정확도나 다른 이미지의 성능을 확정할 수 없다. RF 중요도에서 통계가 약 43.7%를 차지했지만, 이는 새 특징을 사용했다는 뜻이지 정확도를 개선했다는 증거는 아니다.

## 시간과 동작 검증

RTX 2060 6GB. 공통 최초 계산: 모델 로딩 7.92초, Cellpose 7.92초, 영상 특징 0.43초, 통계 0.91초, PCA 학습 0.79초, 압축 0.08초.

| 구성 | 표본 추출 | RF 학습 | 전체 예측 | 캐시 사용 합계 | 특징 캐시 |
|---|---:|---:|---:|---:|---:|
| 기존 | 0.057초 | 0.690초 | 6.231초 | 6.978초 | 39.30MiB |
| 전경 점수 | 0.055초 | 0.636초 | 5.878초 | 6.569초 | 45.82MiB |
| 통계 | 0.054초 | 0.566초 | 6.112초 | 6.732초 | 45.82MiB |

Cellpose context는 6.52MiB이며 전경 점수 구성에서도 입자 선택 재사용을 위해 전체 context를 캐시한다. 비교 프로세스 peak RSS 2,130MiB, GPU allocated 2,191MiB / reserved 3,242MiB. 메모리 최고치는 후보별 독립 측정이 아닌 프로세스 누적 값이다. 단일 실행의 시간 차이를 정밀한 속도 개선으로 해석하지 않는다.

통계 설정을 켠 별도 GPU API 서버에서 라벨 교환·복원·삭제와 원본/501×500 작업 크기의 PNG·ZIP 픽셀 일치를 확인했다. 라벨 교환으로 미라벨 457,281픽셀의 예측이 바뀌었으며 라벨을 복원하면 동일해졌다. 수정 후 요청은 7.04초, 복원은 6.92초였다. 첫 Cellpose 요청 27.62초, 이후 첫 RF 요청 9.99초, 해상도 변경 후 요청 8.18초로 API 직렬화 등 부가 비용을 포함한다.

단위 테스트로 통계 캐시와 공통 PCA 재사용, 설정 변경 초기화, 희소 인스턴스 ID, 홀수 크기, 접촉 입자 경계, 원본 픽셀 단위 환산, 빈 마스크를 검증했다. 한 인스턴스 내부의 서로 다른 클래스와 Cellpose 밖의 픽셀 예측도 확인했다. 두 클래스 미만이면 특징 추론과 PCA 학습을 시작하지 않는다.

## 재현

실험 데이터와 생성 이미지는 저장소에 포함하지 않는다. 이 문서는 당시 측정 결과와 선택 근거를 보존한 요약이다.

앱에는 배경 학습 라벨이 없는 경우 안내와 클래스별 학습 표본 수를 추가했다. 배경 정답이 없을 때 입자 외부를 자동으로 배경 학습 라벨로 넣지는 않는다.
